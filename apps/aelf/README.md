# aelf-plugin
aelf Plugin for aelf Studio IDE.

## How to get started
### Remote plugin
To use it, open the plugin manager in aelf Studio and click the `Activate` button in front of the `aelf` button in the plugin section.

## How to use plugin
1. Write C# code(.cs) in the editor
2. Click Compile button
3. Now you can deploy the contract in the Run tab!

## Load example contracts
It is possible to clone the aelf repository in aelf Studio in order to use example contracts. Click on `Clone aelf Repository`.
Once it is cloned, you will find the contract in the `examples` folder.
